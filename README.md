# Twitchy

A Chrome extension that shows 7TV, BetterTTV and FrankerFaceZ emotes in Twitch chat.

## Install

Requires Node.js 20 or later.

```sh
npm install
npm run build
```

Then open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and pick the `dist` folder.

## Run in development

```sh
npm run dev
```

Load the `dist` folder the same way. Changes reload automatically while `npm run dev` is running.

Run the tests with `npm test`.
